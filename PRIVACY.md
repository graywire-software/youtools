# YouTools privacy policy

YouTools has no analytics or personal-information collection service. It does not send information to a server or sell information.

The extension operates locally on the desktop YouTube website. It reads the page's displayed structure to add player controls, hide the categories you select, customize sidebar appearance and order, and optionally override its theme-color metadata and document title. The current native title is held in page memory for restoration, not saved as browsing history. It does not record watched videos, searches, account information, or page contents.

YouTools stores on/off preferences, sidebar navigation order, selected colors, custom title text, and synchronization revision metadata in local extension storage. If the configured PWA Customizer extension is also installed in the same browser profile, the two extensions automatically mirror only their YouTube color and title preferences using Chrome's local extension messaging. Other websites' preferences, page contents, and YouTools sidebar/player/filter settings are not exchanged. These preferences are not sent to a server or synced to another browser. Uninstalling YouTools removes its own storage; any mirrored copy in PWA Customizer remains there until reset or removed.

YouTools has no analytics, advertising, tracking, external service, remote code, or account requirement. It does not block advertisements or interfere with ad playback. YouTube's own data practices and any other extensions you use are governed by their respective policies.

This policy covers YouTools version 0.6.1. A developer contact method should be supplied in the Chrome Web Store listing before publication.
